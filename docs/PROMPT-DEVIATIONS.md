# PROMPT-DEVIATIONS.md — 任务要求 vs 实际执行的偏离对账

> **为什么要单独留一份**：我（执行方）在几轮里反复报「完成 / 全绿」，
> 但验的是**我自己定义的那套东西**，不是任务原文的条款 —— 两者不是一回事。
> 这份表把**逐条对账**固定下来：哪些达到、哪些偏离、偏离的理由是什么。
>
> 用途：下次有人（人或 Agent）接手时，先看这张表，就知道**哪些是承诺、哪些是权宜**。
>
> 维护规则：**每完成一轮任务就更新**。偏离项只许减少，新增必须写明理由。
